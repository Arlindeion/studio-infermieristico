# Font self-hosted

Il sito serve localmente le famiglie definite in `docs/BRAND_SYSTEM.md`:

- Atkinson Hyperlegible, pesi 400 e 700;
- Bricolage Grotesque, pesi 500, 600, 700 e 800.

I file WOFF2 provengono dai repository ufficiali e sono fissati alle revisioni indicate per rendere l'origine riproducibile:

- [googlefonts/atkinson-hyperlegible](https://github.com/googlefonts/atkinson-hyperlegible/tree/1cb311624b2ddf88e9e37873999d165a8cd28b46), revisione `1cb311624b2ddf88e9e37873999d165a8cd28b46`;
- [ateliertriay/bricolage](https://github.com/ateliertriay/bricolage/tree/84745e5b96261ae5f8c6c856e262fe78d1d6efdd), revisione `84745e5b96261ae5f8c6c856e262fe78d1d6efdd`.

Entrambe le famiglie sono distribuite con SIL Open Font License 1.1. La licenza di ciascuna famiglia è conservata nella relativa sottocartella.
